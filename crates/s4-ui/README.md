# s4-ui

UI integration contracts (headless). Rendering implementations are separate.

## Public API

| Module | Purpose |
|--------|---------|
| `view` | `View`, `ViewId`, `ViewState` |
| `component` | `Component`, `ComponentKind` |
| `theme` | `Theme`, `ThemeTokens` |
| `bridge` | `UiBridge` trait for IDE/web frontends |
