# s4-cli

Command-line interface for the SynapticFour Method Platform.

## Binary

`s4` — primary CLI entry point.

## Subcommands (skeleton)

| Command | Purpose |
|---------|---------|
| `init` | Initialize a workspace |
| `analyze` | Run analysis pipeline |
| `query` | Query the knowledge graph |
| `verify` | Run verification |
| `certify` | Issue certification |
